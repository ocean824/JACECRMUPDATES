T001: Fix p-retry Import in Outbox Webhook Sender (Production Build Crash)
Blocked By: []
Details:
The outbox webhook sender (server/services/bondaiWebhook.ts) imports p-retry as import pRetry from "p-retry" — a default import
In production, esbuild bundles this as (0, OY.default) which evaluates to undefined because p-retry is a pure ESM package that doesn't have a default export in CJS interop
Fix: Change to dynamic import or use a compatible import pattern. The simplest fix is to replace p-retry with a manual retry loop (3 retries, exponential backoff) to eliminate the dependency entirely
This is why all outbox webhook deliveries are failing in production — the dispatcher retries but hits the same error every time
Files: server/services/bondaiWebhook.ts
Acceptance: Outbox webhook sender works in production without p-retry import errors
