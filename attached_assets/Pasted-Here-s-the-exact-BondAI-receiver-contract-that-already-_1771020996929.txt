Signature Rule (EXACT)

BondAI expects:

X-Webhook-Timestamp = Date.now().toString() (epoch ms)

body = exact raw JSON string of the request body above (stringified)

signaturePayload = ${X-Webhook-Timestamp}.${body}

X-Webhook-Signature = HMAC_SHA256_HEX(BONDAI_WEBHOOK_SECRET, signaturePayload)

This is exactly what your repo’s sender does.

Alignment note for Manual Settle

If you want Manual Settle to match BondAI 1:1, then on confirm you must send the same envelope + headers and keep the payload fields/types exactly:

tradeId number (BondAI correlation)

sessionId string (JACE settlement session id)

amount string (your DB uses decimal, Drizzle returns string)

plus the rest as shown

So for Manual Settle, either:

require the admin to enter/select a BondAI tradeId when “Notify BondAI” is enabled, or

don’t send the webhook if there’s no tradeId (otherwise you’ll deviate from BondAI’s receiver schema).
