1. POST /api/jace/webhook — Server-to-server webhook (routes.ts:3468)

This is the one designed for external systems. JACE calls this endpoint after onboarding completes. It:

Verifies signature via X-Jace-Signature header (if JACE_WEBHOOK_SECRET is configured)

Looks for event type investor.onboarding.completed

Finds the user by investorEmail from the event payload

Sets isJaceLive: true and jaceOnboardedAt on that user

No auth session required — it uses signature verification instead

Example payload:

{
  "type": "investor.onboarding.completed",
  "investorEmail": "investor@example.com",
  "completedAt": "2026-02-07T12:00:00Z"
}
